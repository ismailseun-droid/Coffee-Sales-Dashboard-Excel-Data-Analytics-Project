# ☕ Coffee-Sales-Dashboard-Excel-Data-Analytics-Project

## 📌 Project Overview
This project analyzes coffee sales data using Microsoft Excel to uncover trends in revenue, customer purchasing behavior, product performance, and geographic sales distribution.

The project demonstrates an end-to-end Excel analytics workflow including data cleaning, data enrichment, Pivot Tables, dashboard development, and business insight generation.

---
## 🎯 Project Objective
The goal of this project was to transform raw coffee sales data into an interactive dashboard that enables users to:
* Monitor sales performance                  * Identify top customers
* Analyze sales trends over time             * Compare performance across countries
* Evaluate product demand by coffee type

---
## 🛠️ Tools & Techniques
* 📊 Microsoft Excel                        * 🔄 Data Cleaning & Transformation
* 🔗 XLOOKUP / INDEX Data Enrichment        * 📈 Pivot Tables
* 📉 Pivot Charts                           * 🎛️ Interactive Dashboard Design
* 📅 Timeline & Slicer Filters

---
## 📂 Dataset
The project utilizes three datasets:
### 🧾 Orders: Transaction-level coffee sales records.
### 👥 Customers: Customer information, including country and loyalty card status.
### ☕ Products: Coffee product details including coffee type, roast type, size, pricing, and profitability.

---
## 🚀 Dashboard Features

### 💰 Sales Performance
* Total sales tracking                        * Monthly sales trends
* Year-over-year performance analysis

### 🌍 Geographic Analysis
* Sales by country                            * Regional performance comparison

### 👤 Customer Analysis
* Top 5 customers by sales                    * Customer purchasing patterns

### ☕ Product Analysis
* Sales by coffee type                        * Product performance comparison
* Revenue contribution analysis

### 🎛️ Interactive Filtering
Users can dynamically filter results by:
* Size        * Roast Type      * Loyalty Card Status     * Time Period

---
## 🔍 Key Insights
* The United States generated the highest sales among all countries.
* Certain coffee varieties consistently outperformed others in revenue generation.
* A small group of customers contributed a significant share of total sales.
* Sales trends varied across months and years, highlighting seasonal purchasing patterns.

---
## 💡 Business Recommendations
1. Focus marketing efforts on high-performing coffee products.
2. Strengthen customer retention initiatives for top customers.
3. Expand sales strategies in high-performing regions.
4. Leverage loyalty programs to encourage repeat purchases.
5. Use sales trend analysis to improve inventory planning.
